# Sonali Sarode Makeover — Website

Premium single-page website for **Sonali Sarode Makeover**, bridal & occasion makeup artistry based in Nashik, Maharashtra (travels for bookings).

Pure static site — HTML, CSS, vanilla JS. No build step: open `index.html` or deploy the repo root to Vercel.

- Enquiries: WhatsApp chat + on-site form (composes a pre-filled WhatsApp message)
- Imagery slots are mapped in `IMAGE_MANIFEST.md` (placeholder plates until the real Instagram photos are dropped in)
- Set the booking number in `js/main.js` (`WHATSAPP_NUMBER`)
